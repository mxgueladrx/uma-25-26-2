Resolución de sistemas de ecuaciones problemáticos

Crear una matriz y resolver sistemas

Hay que dar mínimo el número de filas o columnas.

A <- matrix(
  c(1, 2, 3, 
    4, 5, 6, 
    1, 2, 4), 
  ncol = 3, 
  byrow = TRUE)

b <- matrix(
  c(0, 0, 1),
  ncol = 1)

# Determinante de una matriz
det(A)
[1] -3
# Método básico de R: solve()
solve(A, b)
     [,1]
[1,]    1
[2,]   -2
[3,]    1
# Qué pasa si A no es regular o si el sistema es incompatible
A_singular <- matrix(
  c(1, 2, 3, 
    4, 5, 6, 
    1, 2, 3), 
  ncol = 3, 
  byrow = TRUE)

det(A_singular)
[1] 0
# solve(A_singular, b) falla

El error U[3,3] = 0 significa que la matriz triangular superior, el índice [3,3] es 0, por lo que no se puede resolver. Ha usado factorización LU.

Cholesky

A <- matrix(
  c(4, 2, -2, 
    2, 10, 2, 
    -2, 2, 5), 
  nrow = 3, 
  byrow = TRUE)
b <- c(6, 15, 12)

# 1. Calcular la descomposición
R <- chol(A) # R es triangular SUPERIOR
R
     [,1] [,2]      [,3]
[1,]    2    1 -1.000000
[2,]    0    3  1.000000
[3,]    0    0  1.732051
t(R) %*% R # Obtenemos A de nuevo (traspuesta(R) * R)
     [,1] [,2] [,3]
[1,]    4    2   -2
[2,]    2   10    2
[3,]   -2    2    5
# Primero hay que resolver R^T * y = b
y <- forwardsolve(t(R), b)

# Después resolvemos R*x = y
x <- backsolve(R, y)
x
[1] 3.2777778 0.1111111 3.6666667

QR

Para resolver un sistema

A <- matrix(
  c(1, 2, 3, 
    4, 5, 6, 
    1, 2, 4), 
  ncol = 3, 
  byrow = TRUE)

b <- matrix(
  c(0, 0, 1),
  ncol = 1)

qr.solve(A, b)

Estructura de matrices

library(Matrix)

n <- 5000

# 1. Matriz densa (R base)
A_densa <- matrix(0, nrow = n, ncol = n)
A_densa[1, 1] <- 5
A_densa[n / 2, n / 2] <- 5
A_densa[n, n] <- 5

# 2. Matriz dispersa (Paquete Matrix)
# Creamos una matriz especificando solo las posiciones (i, j) y los valores (x)
A_dispersa <- sparseMatrix(
  i = c(1, n / 2, n),
  j = c(1, n / 2, n),
  x = 5,
  dims = c(n, n)
)

print(object.size(A_densa), units = "MB")
190.7 Mb
print(object.size(A_dispersa), units = "KB")
21 Kb
