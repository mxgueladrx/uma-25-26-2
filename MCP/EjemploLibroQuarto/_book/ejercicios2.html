5  Ejercicio 2.1

  1. Adapta el código del Ejemplo 2.5 para crear una matriz \(A\) de \(100 \times 100\) que sea pentadiagonal.
  2. La diagonal principal debe tener el valor ‘10’.
  3. Las primeras sub/super-diagonales deben tener el valor ‘-2’.
  4. Las segundas sub/super-diagonales (es decir, \(a_{i, i+2}\) y \(a_{i, i-2}\)) deben tener el valor ‘1’.
  5. Visualiza la estructura de la matriz resultante con image(A).
library(Matrix)

n <- 5
# 1. Definir las diagonales
diag_principal <- rep(10, n)
sub_diag_1 <- rep(-2, n - 1)
super_diag_1 <- rep(-2, n - 1)
sub_diag_2 <- rep(1, n - 2)
super_diag_2 <- rep(1, n - 2)

# 2. Definir las posiciones (i, j)
i_idx <- c(1:n, 2:n, 1:(n - 1), 3:n, 1:(n - 2))
j_idx <- c(1:n, 1:(n - 1), 2:n, 1:(n - 2), 3:n)
x_val <- c(diag_principal, sub_diag_1, super_diag_1, sub_diag_2, super_diag_2)

# 3. Crear la matriz dispersa
A <- sparseMatrix(
  i = i_idx, 
  j = j_idx, 
  x = x_val,
  dims = c(n, n)
)

5.3 Ejercicio 2.4

Usando sparseMatrix(), construye una matriz \(A\) de \(100 \times 100\) que tenga la diagonal principal llena de ‘5’, las segundas subdiagonales (k=-2) y superdiagonales (k=2) llenas de ‘1’, y el resto ceros. Visualízala con image(A).

n <- 100
# 1. Definir las diagonales
diag_principal <- rep(5, n)
sub_diag_2 <- rep(1, n - 2)
super_diag_2 <- rep(1, n - 2)

# 2. Definir las posiciones (i, j)
i_idx <- c(1:n, 3:n, 1:(n - 2))
j_idx <- c(1:n, 1:(n - 2), 3:n)
x_val <- c(diag_principal, sub_diag_2, super_diag_2)

# 3. Crear la matriz dispersa
A <- sparseMatrix(
  i = i_idx, 
  j = j_idx, 
  x = x_val,
  dims = c(n, n)
)

image(A)
