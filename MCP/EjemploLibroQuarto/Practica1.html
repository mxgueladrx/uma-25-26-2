Practica1

Objetivo: Modelar un problema físico simple que genera un sistema de ecuaciones grande y disperso, y comparar la eficiencia de los métodos de resolución.

Problema: Imaginemos una barra de metal de 1 metro. Mantenemos el extremo izquierdo a 0ºC y el extremo derecho a 100ºC. Queremos encontrar la temperatura en equilibrio en puntos interiores de la barra.

  1. Creamos nuestra matriz y vector con n = 1000:
library(Matrix)

n <- 1000
# 1. Definir las diagonales
diag_principal <- rep(2, n)
sub_diag <- rep(-1, n - 1)
super_diag <- rep(-1, n - 1)

# 2. Definir las posiciones (i, j)
i_idx <- c(1:n, 2:n, 1:(n - 1))
j_idx <- c(1:n, 1:(n - 1), 2:n)
x_val <- c(diag_principal, sub_diag, super_diag)

# 3. Crear la matriz dispersa
A <- sparseMatrix(
  i = i_idx, 
  j = j_idx, 
  x = x_val,
  dims = c(n, n)
)

# 4. Crear el vector b
b <- rep(0, n)
b[n] <- 100
  1. Resolver y comparar tiempos: ya teniendo nuestras matrices, vamos a comparar los tiempos de ejecución resolviendo el sistema de distintas formas.
library(microbenchmark)
library(Rlinsolve)

mbm <- microbenchmark(
  "R base" = solve(A, b),
  "Cholesky" = {
    R <- chol(A)
    y <- forwardsolve(t(R), b)
    x <- backsolve(R, y)
  },
  "QR" = qr.solve(A, b),
  "Jacobi" = lsolve.jacobi(A, b, verbose = FALSE),
  "Gauss-Seidel" = lsolve.gs(A, b, verbose = FALSE),
  "Gradiente Conjugado" = lsolve.cg(A, b, verbose = FALSE),
  times = 1
  )
  
print(mbm, unit = "ms")
